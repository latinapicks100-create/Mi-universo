## 🚀 Publicar en GitHub Pages

### Paso 1 — Instala dependencias
```bash
npm install
```

### Paso 2 — Crea tu repo en GitHub
Ve a github.com → New repository → Nombre: `mi-universo` → Create

### Paso 3 — Sube el código
```bash
git init
git add .
git commit -m "✨ Mi app del universo"
git remote add origin https://github.com/TU-USUARIO/mi-universo.git
git push -u origin main
```

### Paso 4 — Despliega
```bash
npm run deploy
```

### Paso 5 — Activa GitHub Pages
GitHub → Tu repo → Settings → Pages → Branch: **gh-pages** → Save

### ✅ Tu app estará en:
```
https://TU-USUARIO.github.io/mi-universo/
```

Guárdala en la pantalla de inicio de tu móvil 📱
